Beat Marker 0.4.0 bundles the background analysis engine for Blender.

Download the named ZIP for your operating system and processor, then use Blender **Preferences → Get Extensions → Install from Disk**. The automatic GitHub source archives do not contain the engine.

The packages contain the trained Beat This! model, private Python runtime, FFmpeg and FFprobe. Premiere Pro, system Python and a separate FFmpeg installation are not required. Audio analysis is offline.

Existing music-marker controls, beat-number checkboxes, source anchors, alignment preview, optional ripple and whole-operation Undo are preserved.

This is a prerelease. Frozen-engine checks run on native build runners; interactive Blender editing has currently been checked on Apple silicon macOS. See the README and build documentation for platform details and existing editing limitations.
